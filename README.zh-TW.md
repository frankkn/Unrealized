# UNREALIZED 📔 人生存摺

**選一個出生年代與性別，從童年一路走到晚年，每一章做一個選擇。走到最後翻開存摺，看看你蓋出了什麼樣的人生——以及有哪些結局，你的時代從一開始就沒給過你。**

🔗 Live：**https://frankkn.github.io/Unrealized/**

## 如何遊玩

用瀏覽器直接開啟 [https://frankkn.github.io/Unrealized/](https://frankkn.github.io/Unrealized/)。不用註冊、不用安裝、沒有後端。

也可以直接從硬碟跑——把 repo 下載下來，雙擊 `index.html` 就能玩。沒有建置流程、沒有打包工具，這是刻意的設計約束，不是偷懶。

1. 選一個世代——**1975 / 1990 / 2005**——與性別
2. 從第 0 章走到第 7 章，從你出生的那個家，一路走到五十歲之後
3. 五軸屬性——財務、成就、關係、健康，以及**自我一致**（你做的選擇有多接近你真正想要的）——全程都在動，但**到最後一刻才揭曉**
4. 第 2 章起隨時可以收手：「**就在這裡收尾，看看我的存摺**」。中途停下有自己的五個結局
5. 圖鑑分成三個世代分頁，每頁只認你用那一代做到的事。用 1990 解到的結局，在 1975 那頁仍然是未解鎖——用 1975 走到它是另一件成就。世代限定的結局則根本不出現在沒開放給它的那一頁

**36 個完整結局 + 5 個中途結局。** 其中有些是世代限定。

## 這是什麼

一款發生在台灣的繁體中文人生選擇遊戲。

三個人相隔三十年出生在同一個國家。他們考不同的試、當不同長度的兵、走進不同的房市，並且在完全不同的年紀遇上同婚法案——太晚、剛剛好、或早到他們從不知道這曾經是個問題。

UNREALIZED 建立在一個想法上：**人生不只由你的選擇決定，還取決於你是哪一屆。**

名字取自會計術語「未實現損益」，同時也是「未實現的可能」。它是唯一一個能讓最好的結局和最壞的結局共用同一個標題的字。

### 產品規則（不可妥協）

- **選擇要有質地，但不必然課稅。** 每個選項至少變動兩軸、五軸加總不超過 +3——足以讓單一選擇無法翻盤整局，同時容許一個選項就是件好事。原本的規則要求每個選項都得付出代價，實作出來卻變成「每一個顧健康、顧家庭、慢下來的選項都在扣事業」，那是比原意悲觀得多的主張
- **但「沒有免費的選擇」講的是取捨，不是衰退。** 選擇之外還有一條基線：出社會之後薪水與年資本來就會長；到了晚年職位會還回去、身邊的人會慢慢散掉、身體會開始還債。少了這條，遊戲等於在說「人的一生是淨損耗」。基線刻意壓得比任何單一選擇都輕——**選擇仍然是主角**
- **`自我一致` 永遠不會自己長。** 財務、成就、關係都會隨時間累積，唯獨「活得接近自己真正想要的樣子」這件事，只能用一個一個決定去換
- **毀滅結局必須可預防、有伏筆。** 敘述會提醒你——「你已經三年沒做健檢」——但永遠不顯示數值。車禍節點只在你選過「連續加班後騎車」或健康已經很低時才會出現。**純隨機懲罰是不合格的設計**
- **不寫自殺結局，不寫自殺方式。** 死亡把後果一次結清，玩家不用面對任何東西。真正痛的是活下來，所有財務崩潰類結局都往這個方向寫
- **屬性全程隱藏。** 你是照著敘述在選，就像當年的你一樣——不是在最佳化一個數字
- **不做真實政治人物、政黨的指名褒貶。** 第 6 章那個因為政治而撕裂的家庭，寫的是餐桌安靜下來，不寫哪一邊對
- **有些結局鎖在特定世代。** 圖鑑本身就在講一件事：**有些結局你這輩子解不到，因為你的時代沒把它放進選單。**

## 三個世代

| | 1975（民國64年生） | 1990（民國79年生） | 2005（民國94年生） |
|---|---|---|---|
| 童年 | 三代同住／眷村／農村 | 公寓、雙薪、鑰匙兒童 | 獨生子女，父母正好是1990那一代 |
| 升學 | 高中聯考、大學聯考，錄取率約三成 | 學測指考、錄取率破九成、學歷通膨 | 108課綱、學習歷程，考得上但學校可能倒 |
| 兵役（男） | 兩年 | 一年 | 四個月→2024恢復一年，正好卡到 |
| 出社會 | 1997亞洲金融風暴、台商西進、竹科起飛 | 22K、無薪假、太陽花 | AI衝擊、疫情世代、遠距常態 |
| 房子 | 還買得起（2003年前） | 眼睜睜看它漲走 | 已不在討論範圍 |
| 同婚 | 一輩子都在非法與汙名中 | 2019通過時29歲，剛好趕上 | 從小就知道這是合法的 |
| 演到 | 2025，50歲 | 2040，50歲 | 2055–2075，近未來推想 |

**性別不開新支線，只改內容。** 第 3 章是最尖銳的一次分歧：男性進兵役，女性進「提早兩年」的職場。**兩邊都不是好處，是不同的成本。**

2005 世代的父母設定成 1990 世代。玩過 1990 再玩 2005，你會發現自己在扮演上一輪主角的小孩。第 0 章留了線索，但從不說破。

## 誠實靠基礎設施保證

上面那些規則是由腳本檢查的，不是靠自律。每次改動都跑 `node dev/test-engine.js`，以下任一項不過就失敗：

- **失控的選項**——每個選項都會被掃過「兩軸／淨值 ≤ +3」這條規則，沒有任何既有內容能豁免
- **斷掉的節點圖**——從起點走不到的節點，以及指向不存在節點的選項
- **死掉的結局**——36 個全部都必須被證明可達。隨機亂玩走不到全部，剩下的用針對性腳本證明。其中 4 個條件範圍太窄（五軸要同時落在中段、或某一軸要精準停在某個值），改成重播 `dev/find-paths.js` 離線搜到的實際路徑
- **走不通的章節**——第 0–3 章全枚舉，每一條分支、六種世代 × 性別組合
- **壞掉的介面**——`node dev/test-ui.js` 把 `index.html` 交給一個真的 DOM，從磁碟把每一支 script 內嵌進去，然後模擬點擊玩到結局：六種世代 × 性別、中途收尾、世代限定選項在 1975 出現而在 2005 隱藏、多段落結局、圖鑑、清除紀錄、減少動畫、快速重玩。`<script src>` 打錯字、element id 拿錯、事件沒綁上——這些會在這裡失敗，而不是在玩家面前
- **漏掉的佔位符**——詞彙字典會依世代把 26 組用語替換進劇本（`{起薪}` 變成「兩萬四」「二萬二」或「三萬六（但房租一萬八）」），渲染後不允許有任何 `{token}` 殘留

健康軸的問題就是這樣被抓出來的。它不知不覺變成了「這個選項需要一個代價就扣它」的萬用軸，連敘述跟身體毫無關係的節點也在扣：153 個選項裡正向總和 +4、負向總和 −44，44 個節點裡有 40 個完全沒有任何選項能回血。不管怎麼玩，90% 的人都死於健康歸零。它看起來像難度問題，實際上是歸因問題——現在那些代價由敘述真正支撐的軸來承擔。

## 技術

純 HTML + CSS + vanilla JS。無框架、無打包工具、無建置流程、無後端、無 API、無追蹤、無分析。**要玩不用裝任何東西**——唯一的開發依賴只是讓測試能驅動一個 DOM，永遠不會進到遊戲裡。

用一般 `<script>` 逐一載入而不是 ES module，就是為了讓人下載 zip 之後在 `file://` 底下也能直接玩。全域命名空間統一掛在 `window.UNREALIZED` 底下。

localStorage 只存結局圖鑑、設定、上一局的世代——沒別的了——遊戲裡有清除按鈕。所有讀寫都包了 try/catch，隱私模式下會降級而不是整個掛掉。

```
index.html              入口
css/style.css           全部樣式
js/engine.js            狀態機、屬性運算、結局判定
js/state.js             存檔／圖鑑（localStorage）
js/ui.js                DOM 操作、動畫、章節轉場
data/config.js          世代設定、詞彙字典、屬性定義、章節基線
art/                    生成的場景圖，一個節點一張
art/PROMPTS.md          45 個 prompt，一個節點一則
data/nodes-ch0-3.js     第 0–3 章
data/nodes-ch4-5.js     第 4–5 章
data/nodes-ch6-7.js     第 6–7 章
data/endings.js         全部結局
dev/                    開發工具，不是遊戲的一部分
```

**內容與引擎完全分離。** 引擎不認識任何劇情——把整個劇本重寫一遍也只會動到 `data/`。

## 開發

```bash
npm install          # 只為了介面測試用的 jsdom
npm test             # 引擎 + 介面
npm run test:engine  # 只測引擎，完全不需要任何依賴
npm run test:ui      # 只測介面，跑在真的 DOM 上
npm run find-paths -- 3000 > paths.txt && npm run swap-paths -- paths.txt   # 重新產生稀有結局的證明路徑並貼回測試
```

**這個依賴只給測試用，永遠不給遊戲用。** `index.html` 仍然可以什麼都沒裝就直接從硬碟打開——那正是「零建置」這個約束的意義，而且這件事本身就被介面測試守著，因為它就是照瀏覽器的方式載入整個頁面的。

稀有結局在測試裡是用重播固定路徑來證明的，所以**任何數值平衡的改動都會讓它們失效**——那就是 `find-paths.js` 存在的理由。健康軸重新平衡弄壞了四條裡的三條；加上章節基線之後四條全壞。兩次都是：重跑、貼回去、收工。

### 部署

Settings → Pages → Source 選 *Deploy from a branch*，branch 選 `master`、目錄 `/ (root)`。repo 根目錄的 `.nojekyll` 會讓 Pages 跳過 Jekyll。

## 刻意不做的東西

帳號、雲端存檔、排行榜、成就系統、分享解鎖、任何形式的分析、難度設定、回上一步，以及遊戲進行中的屬性顯示——看得到數字，人生就變成一張試算表，而那是這個東西唯一不能變成的樣子。
